# Руководство пользователя Vibe Viewer

## Назначение

Vibe Viewer открывает файлы в собственном окне без запуска Word, LibreOffice, браузера,
архиватора, медиаплеера и других сторонних приложений. Интерфейс состоит из двух панелей:
слева находится предпросмотр, справа — дерево файлов.

## Установка

Требуется Python 3.11 или новее. На macOS и Linux из корня проекта выполните:

```bash
make install
make run
```

`make install` создаёт `.venv`, устанавливает зависимости из `requirements.txt` и саму
программу в editable-режиме. Последующие изменения исходного кода сразу используются при
следующем запуске.

Для чистой Ubuntu предусмотрена одна команда:

```bash
make ubuntu-install
make run
```

Она устанавливает Python, шрифты и системные библиотеки, необходимые Qt. Пароль может
потребоваться только системному менеджеру пакетов Ubuntu.

## Работа с интерфейсом

1. Нажмите **Открыть файл** для выбора одного файла или **Открыть папку** для перехода к
   нужному каталогу.
2. Один щелчок по файлу в правой панели открывает его во встроенном просмотрщике.
3. Щёлкните заголовок **Имя**, **Размер**, **Тип** или **Дата**, чтобы изменить сортировку;
   повторный щелчок меняет направление.
4. Папки без прав чтения отмечаются текстом **(нет доступа)**, имеют предупреждающий
   цвет и не раскрываются. После изменения системных прав нажмите **Обновить**.
5. Список зарегистрированных форматов доступен через меню
   **Вид → Поддерживаемые форматы**.

Если специализированный декодер не смог прочитать повреждённый файл, приложение не
закрывается и предлагает безопасный HEX-предпросмотр.

## Уровни предпросмотра

- **Визуальный** — страницы документов, изображения, аудио и видео.
- **Содержимое** — текст, исходный код, таблицы, офисные документы и сообщения.
- **Структура** — архивы, базы данных, научные данные, геоданные и 3D-модели.
- **Метаданные** — заголовки сложных или потенциально опасных бинарных форматов.
- **HEX** — универсальный запасной режим для неизвестных данных.

Регистрация расширения не означает пиксельное воспроизведение исходного приложения.
Например, DOCX показывает абзацы, таблицы и изображения, а CAB и PST — безопасные
метаданные без извлечения содержимого. Подробности приведены в
[`FORMATS.md`](FORMATS.md).

## Команды проекта

| Команда | Назначение |
|---|---|
| `make` | показать краткую справку |
| `make install` | создать окружение и установить программу |
| `make run` | запустить Vibe Viewer |
| `make samples` | создать локальные демонстрационные файлы |
| `make test` | выполнить тесты |
| `make check` | выполнить тесты и проверку стиля |
| `make build` | собрать wheel в `dist/` |
| `make test-ubuntu` | проверить проект в Ubuntu-контейнере |
| `make screenshot-ubuntu` | сохранить контрольный снимок X11-интерфейса |
| `make docs` | собрать HTML-документацию Doxygen |

## Виртуальные машины и программная графика

В Linux по умолчанию включён программный графический backend и отключено проблемное
аппаратное декодирование видео. Это устраняет ошибки VA-API, EGL и Zink в виртуальных
машинах. На компьютере с настроенными драйверами ускорение можно вернуть командой:

```bash
VIBE_VIEWER_HARDWARE_ACCELERATION=1 make run
```

## Ограничения

- Набор реально воспроизводимых медиакодеков зависит от Qt Multimedia/FFmpeg на
  установленной платформе.
- Старые бинарные DOC/PPT и некоторые электронные книги показываются в структурном или
  экспериментальном режиме.
- PostScript (`.ps`) показывает встроенную структурную сводку без Ghostscript; это не
  постраничная растровая отрисовка. DIF и SYLK показывают основные табличные записи.
- Зашифрованные архивы и документы могут не открыться без пароля; приложение не пытается
  обходить защиту.
- Просмотр предназначен для знакомства с содержимым, а не для редактирования файлов.
